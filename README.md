# Nisarg Nature Estates

Static, mobile-responsive React + Vite website for a plot-selling project.

## Run

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:

npm install
npm run dev

4. Open the localhost URL shown by Vite.

## Customize

Edit `src/App.jsx` for:
- Company name
- Phone number
- WhatsApp number
- Email
- Plot sizes and prices
- Location text

Edit `src/App.css` for colors, spacing and design.

The current gallery uses remote Unsplash images. Replace those URLs with your actual project/dam images for the final website.
